# Lessons Learned

- **Axiom Laundering Anti-Pattern:** Encoding physical claims (Jensen's inequality, phase-locking ↔ potential minimization, section agreement from synchronization) as `class` or `structure` fields makes theorems `sorry`-free but tautological — the proof just unfolds the definition that already contains the conclusion. Detectable by: (a) theorems provable by `trivial`, `rfl`, or single `exact` of a class field; (b) class fields that state universally quantified inequalities or implications rather than structural properties. Fix: physical claims that are mathematical theorems must be *proved* from Mathlib primitives; irreducible physical postulates must be collected in an explicit `Axioms.lean` with justification for why they're not derivable.

- **Lean Architecture Translation:** When moving from a continuous PDE approach to a combinatorial/topological hybrid model in Lean, implicit typeclass metavariables (like `IsManifold M`) tied to continuous topology (e.g. `ModelWithCorners`) should not be needlessly propagated into the strictly discrete combinatorial structures (like `KuramotoSystem`). Removing unused continuous variables (`E`, `H`, `I`) from the discrete `Phase 3` Engine resolves stuck typeclass inferences.
- **Migration of Code:** When archiving old modules and implementing a new formalization plan, be sure to update the root library import file (`PhysicsOfConsciousness.lean`) so that `lake build` accurately targets the new pipeline, and archive old active code with specific tags (`v2_`) to prevent naming collisions with older archived versions (`old_`).\
- **Sheaf Axiom & Abstract Gluing:** When mathematically formalizing the gluing of finite measures across local sections (a problem traditionally solved via Carathéodory's extension or Riesz-Markov-Kakutani), one can rigorously bypass manual extension theorem proofs by utilizing Mathlib's `TopCat.Presheaf.sheafify`. This operation correctly transforms the presheaf of finite measures into the sheaf of locally finite (Radon) measures, fully capturing the semantics of a globally coherent unified topological structure without manual `sorry` patching.

- **Lean 4 Integral Decomposition API:** The Lean 4 Mathlib Bochner integral API requires precise typeclass instances. Key patterns:
  - `integral_const c : ∫ _ : α, c ∂μ = μ.real univ • c` — uses `.real` (not `.toReal`); in ℝ, `smul_eq_mul` converts to `*`.
  - `integral_const_mul r f : ∫ a, r * f a = r * ∫ a, f a` — needs `[RCLike]` on the type.
  - `integrable_const c` (not `integrable_const _`) — needs explicit constant to synthesize `NNNorm`.
  - `integral_add hf hg` requires both `hf : Integrable f` and `hg : Integrable g`.
  - Rule: **Always provide explicit integrability witnesses before `rw [integral_add ...]`; never rely on unification holes for them.**
  - Rule: **Use `calc` chains for multi-step integral rewrites** instead of chaining `rw [...]` — each step is independently checkable.

- **Fixed-Point Theorems in Mathlib (as of Lean 4.34.0 / Mathlib commit 5ce203e):**
  - `ContractingWith.fixedPoint f hf` + `hf.fixedPoint_isFixedPt` — Banach contraction, needs `[Nonempty]` + `[MetricSpace]` + `[CompleteSpace]`. **This is the go-to for physics applications.**
  - Brouwer / Schauder fixed-point theorems are **NOT in this Mathlib version** — use Banach contraction as the constructive alternative.
  - `OrderHom.lfp` / `OrderHom.gfp` — Knaster-Tarski for monotone maps on `CompleteLattice`.
  - `IsPreconnected.intermediate_value₂` — IVT-based fixed points for self-maps of `Icc`.
  - Rule: **Check Mathlib availability before assuming a theorem exists** — even well-known results (Brouwer) may not be formalized yet.

- **The `h_mean` Hypothesis Pattern:** When proving minimality of a functional (e.g., entropy production) via Jensen/variance decomposition, the lower bound `c² ≤ ∫f²` only holds when `c = ∫f dμ / μ(M)` (the population mean). This constraint must be made an **explicit hypothesis** in both the lemma and the theorem, not hidden in a class field. This is physically justified by conservation laws (mean frequency conserved in symmetric Kuramoto). Pattern: add `(h_mean : ∫ f = c * μ(M))` as an explicit parameter everywhere needed.

- **Parametric interval integrals are continuous for free.** `intervalIntegral.continuous_parametric_intervalIntegral_of_continuous'` (in `Mathlib/MeasureTheory/Integral/DominatedConvergence.lean`) takes a jointly continuous `f : X → ℝ → E` — supplied as `Continuous f.uncurry`, which `fun_prop` discharges after `unfold`ing the integrand — and returns continuity of `fun x => ∫ t in a..b, f x t`. No dominated-convergence argument has to be written by hand. This is what makes `continuous_vonMisesZ`/`M`/`S` three-line proofs in `Phase8_SelfConsistency.lean`. Needs `[FirstCountableTopology X]` and a locally finite measure; `X = ℝ` with `volume` qualifies.

- **Reach for continuity + IVT before a series expansion.** The supercritical half of `K_c = 2D` was scoped in `tasks/todo.md` as needing "a second-order lower bound on the Bessel ratio, `R(a) ≥ a/2 - C a³`". It needed no expansion at all. Once integration by parts gives `R(a) = a · E(a)` with `E(a) = 𝔼_a[sin²θ]`, the only facts used are that `E` is continuous and `E(0) = 1/2`; `D/K < 1/2` then puts the map above the diagonal near `0` by continuity alone, `R ≤ 1` puts it below at `r = 1`, and `intermediate_value_Icc'` supplies the crossing. **Pattern:** when the goal is *existence* of a root, a qualitative limit plus IVT usually beats a quantitative expansion — the expansion is only needed if the root's location or uniqueness is wanted. The same estimate was wrong in the same direction for mesh refinement and for the subcritical half; this is now three times.

- **`intermediate_value_Icc'` for a decreasing crossing.** `intermediate_value_Icc (hab : a ≤ b) (hf : ContinuousOn f (Icc a b)) : Icc (f a) (f b) ⊆ f '' Icc a b` is for `f a ≤ f b`. When the function starts *above* the target and ends below — the usual shape for a fixed-point argument on `f r = R(r) - r` — the primed version `intermediate_value_Icc'` takes `Icc (f b) (f a)` instead. Picking the wrong one produces an unprovable membership goal, not a type error.

- **`mul_lt_mul_left` needs an ordered-algebra instance that ℝ does not always route to.** `(mul_lt_mul_left h).mpr` failed with `failed to synthesize MulRightStrictMono ℝ`. `mul_lt_mul_of_pos_left hE hpos` is the form that works for `c * a < c * b` from `a < b` and `0 < c`.

- **Complex-valued interval integrals need no special API.** To evaluate `∫ θ in a..b, Complex.exp (I * θ) * (f θ : ℂ)` for real `f`: rewrite the integrand *pointwise* into `((g θ : ℝ) : ℂ) + ((h θ : ℝ) : ℂ) * I` (via `mul_comm I _`, `Complex.exp_mul_I`, then `push_cast; ring`), then `intervalIntegral.integral_add`, `intervalIntegral.integral_mul_const` and `intervalIntegral.integral_ofReal` reduce it to two real integrals. No `integral_re`/`integral_im` and no `RCLike` gymnastics. Used for `circularOrderParameter_vonMises` in `Phase8_SelfConsistency.lean`.

- **Odd integrand on a symmetric interval: there is no Mathlib lemma, and the two-line proof is worth remembering.** For `∫ x in -c..c, f x = 0` with `f (-x) = -f x`, combine `intervalIntegral.integral_add_adjacent_intervals` (splitting at `0`) with `intervalIntegral.integral_comp_neg` (which gives `∫ x in 0..c, f (-x) = ∫ x in -c..0, f x`), `simp only` the oddness lemma plus `intervalIntegral.integral_neg` and `neg_zero` into the second, then `linarith`. The even case in the same file (`vonMisesC2_eq_two_mul`) is the identical shape without the `integral_neg`.

- **A definition whose physical meaning lives only in its doc-string is a soft version of axiom laundering.** `selfConsistency K D r` was literally `besselRatio (K * r / D)`; every theorem about it was true of an arbitrary function of `r`, and the reading "`r` is the order parameter of the density `r` induces" was prose. The fix is a theorem, not a comment: define the object the prose names (here the density and its order parameter) and prove the definition computes it. Ask of any suggestively-named `def`: *what theorem would be false if this were a different function with the same type?* If the answer is "none", the name is doing work the Lean is not.

- **`TangentSpace I x` is a `def`, and its instances are not `ℝ`'s.** Writing the field proofs of a class over `TangentSpace` inline fails with application-type mismatches (`ContinuousLinearMap.mul ℝ ℝ` "has type … but is expected to have type …") even when everything is definitionally equal, because instance search resolves `Mul`/`AddCommGroup`/`Module` for `TangentSpace I x` through `instAddCommGroupTangentSpace` and friends rather than through `ℝ`'s. A `(u : ℝ)` type ascription does **not** repair it — it produces `failed to synthesize HMul (TangentSpace …) …`. The fix that works: state the object and each law as separate `ℝ`-typed top-level lemmas and pass them as the class fields, where a single defeq check succeeds. See `realForm`/`realForm_symm`/`realForm_nondeg` in `Examples.lean` §12.

- **Witness the *degenerate* case, not the simplest case.** The original `ActionPrinciples` witness (`V v = v²` on a one-point spacetime) made two things invisible: with a single vacuum there is no symmetry to break, and on a one-point spacetime `∀ᵐ` and `∀` coincide, so the theorem's actual conclusion could not be distinguished from the stronger one it deliberately avoids. Replacing it with a double well over a two-point spacetime carrying a Dirac measure made both visible and turned a doc-string caveat ("the `∀ x` version is false") into a theorem. **Pattern:** when choosing a witness, pick the smallest one on which the theorem's *weakenings* are observable — a witness that cannot distinguish the statement from a stronger one has not tested it.

- **`TopCat.Presheaf.sheafify` has no inverse in Mathlib, and `GrothendieckTopology.isIso_toSheafify` is not it.** The two sheafifications are different constructions: `CategoryTheory.toSheafify` is the plus-construction unit for a Grothendieck topology and does have `isIso_toSheafify`; `TopCat.Presheaf.toSheafify` is the *stalk-wise* construction (`subsheafToTypes` of the "locally a germ" predicate), and `Mathlib/Topology/Sheaves/Sheafify.lean` still carries a `-- PROJECT` comment where its adjunction would be. So a plan of the form "prove the presheaf is a sheaf, then invert the unit" does not typecheck against the sheafification the development actually uses. What *does* work on a discrete substrate is to build the inverse by hand: the stalk at `x` is a colimit over `OpenNhds x`, and a map out of it is a cocone, so "the mass a germ carries at `x`" is `colimit.desc` of the cocone whose cocone law is exactly that restriction preserves point masses. Injectivity then comes from `exists_germ_eq` plus `germ_res_apply` (restrict any representative to the smallest neighbourhood `{x}`, where a finite measure is one number), and surjectivity from constructing the measure with prescribed point masses. See `Examples.lean` §10.

- **Lévy–Prokhorov is the wrong metric on a discrete substrate, and the failure is quantitative.** `Metric.thickening ε A = A` whenever `ε ≤ 1` on a space whose distinct points are at distance `1`, so the Lévy–Prokhorov condition below scale `1` collapses to `μ B ≤ ν B + ε` for every `B` — but *above* scale `1` the thickening is everything and the distance saturates. The consequence is concrete: `μ ↦ ½μ + ½μ₀` is **not** a `½`-contraction there (two mass-5 point masses at different sites stay at Lévy–Prokhorov distance `1` under it), even though it is one for the uniform distance between densities (and for total variation). Mathlib also proves no `CompleteSpace` instance for `LevyProkhorov`, and only `ProbabilityMeasure` — not `FiniteMeasure` — gets a genuine `MetricSpace` rather than a pseudometric. On a finite discrete space, the uniform distance between densities is the metric to use — equivalent to total variation there, within a factor of the number of points, but not equal to it. It is complete, it makes the relaxation map an exact `½`-contraction, and it agrees with Lévy–Prokhorov below scale `1` anyway.

- **`MetricSpace.induced` plus a surjection is a two-line completeness proof.** To metrize an opaque type `A` that is in bijection with a known complete space `B`: `MetricSpace.induced f hf inferInstance` makes `dist a a' = dist (f a) (f a')` by `rfl`, so a Cauchy sequence in `A` is *definitionally* Cauchy in `B` (`Metric.cauchySeq_iff` transfers by `exact`), its limit is `f`-hit by surjectivity, and `Metric.complete_of_cauchySeq_tendsto` closes it. This is the honest replacement for "with the 0/1 metric a Cauchy sequence is eventually constant", which proves completeness of a space in which completeness means nothing.

- **Type-category morphism applications resist coercions; name the restriction.** `F.map i μ` elaborates fine, but its type displays as `(fun X => X) (F.obj (op V))` and `⇑(F.map i μ) s` then fails with "cannot coerce to function" — and a `(μ : FiniteMeasure ↥U)` ascription does not repair it either, because the ascription is not what instance search sees. The fix that works throughout `Examples.lean` §10 is to wrap the restriction in a `def` with the concrete type (`res hle μ : FiniteMeasure ↥V := F.map (homOfLE hle).op μ`) and state every lemma about `res`. For the same reason, prefer `exact` over `rw` when a hypothesis carries the presheaf-typed version of a measure: `exact` checks up to defeq, `rw` needs syntactic type-correctness at `implicit` transparency and reports an "application type mismatch" that looks like a real error but is not.

- **Demote, don't delete, a superseded instance.** When a better `MetricSpace` instance replaces a degenerate one, keep the old one as a plain `def` (marked `@[instance_reducible]` to silence the class-reducibility warning) and re-enable it only inside a `section` with `attribute [local instance 10000]`. The theorem that records why the old choice was empty (`contracting_implies_const`) then still compiles, still means what it meant, and cannot silently be picked up by the new development. A `show` in its proof that only typechecks under the old metric doubles as a check that the local instance really won.

- **Before hunting for a stronger witness, ask whether the class shape permits one.** O5 asked for a `ThermodynamicCover` "at a non-constant minimum" for two passes running, on the assumption that the constant-phase witness was a failure of imagination. It was not: `thermodynamic_equilibrium` demands a global minimum of the reduced Kuramoto potential, and the minimisers of that functional are *exactly* the phase-locked configurations, so every instance is locked and `phase_invariant_periodic` erases the surviving `2π` differences. The deliverable was the proof of that (`ThermodynamicCover.phase_locked`, `ThermodynamicCover.glued_section_eq`), and it says something the witness never could: the section Derivation 5 glues is the measure `phase_invariant_measure` already carried, so the theorem's content is uniqueness, not emergence. **Pattern:** when a witness obligation keeps discharging trivially, prove the triviality is forced. Two of this development's sharpest results (`contracting_implies_const`, and now this) came from doing that rather than from a better witness. The by-product is worth having anyway — proving the converse of the minimum characterisation (`phase_locked_minimizes_potential'`, hence `potential_min_iff_phase_locked`) is what let the witness carry a phase field that is at least not the constant function.

- **A `def` of class type used as a *field* of another structure instance must be `@[instance_reducible]`.** `noncomputable def cortexSyncTwisted : LocalSectionSynchronization Cortex` elaborated fine on its own, but feeding it to `ThermodynamicCover.mk` produced four *kernel* errors of the form "`_aux_1` has type `LocalSectionSynchronization Cortex → Finset Bool` but is expected to have type `… → Finset (LocalSectionSynchronization.I Cortex)`". The elaborator saw through the `def` and the kernel did not. Marking it `@[instance_reducible]` (which the class-reducibility warning already asks for) fixes it. Use a `def` rather than an `instance` when a second witness for a class that already has one would make instance search silently choose between two different models of the same substrate — then apply it explicitly, `@global_section_from_thermodynamics Cortex _ _ _ cortexCoverTwisted`.

- **When `rw` fails across a `def` type synonym, feed it a `rfl`-proved `have`.** `GlobalSection X` is a `def` for `(probabilityPresheaf X).obj (op ⊤)`; `rw [densityOn_restrict]` on a goal mentioning a section of the second type fails with "the target expression is not type-correct under the `implicit` transparency level", because `rw`'s pattern match will not unfold the synonym while the elaborator will. Stating the instance of the rewrite as `have h : lhs = rhs := rfl` and then `rw [h]` works, because `rfl` is checked at default transparency. This is the same transparency mismatch as the "prefer `exact` over `rw`" note above, in the one situation where `exact` is not available because further rewriting has to follow.

- **Upgrading a fold argument from `≥` to `>` is usually free, and it can settle a boundary case nothing else reaches.** `vonMisesC2_nonneg` proved `I₂(a) ≥ 0` by folding `[-π, π]` onto `[0, π/4]` where the integrand is a product of two non-negative factors. Both are *strictly* positive on the open interval, so the same proof with `Real.cosh_lt_cosh` in place of `Real.cosh_le_cosh`, `Real.sin_lt_sin_of_lt_of_le_pi_div_two` in place of its `≤` cousin, and `intervalIntegral.intervalIntegral_pos_of_pos_on` in place of `integral_nonneg` gives `R(a) < a/2` for `a > 0`. That strictness is what closed `K = 2D`, a case both threshold theorems had explicitly disclaimed for two passes: at the threshold the self-consistency map is tangent to the diagonal at the origin, and only a strict inequality shows the tangency is one-sided. **Pattern:** when a doc-string says "the boundary case is covered by neither theorem", check first whether the existing inequality is strict on the interior — the boundary case is often not a missing theorem but a missing `lt`.

- **A quantifier over *all* solutions can substitute for a uniqueness proof.** The open item asked for uniqueness of the coherent branch, then for continuity in `K` so that "a discontinuous jump at threshold is not excluded" — but continuity of *the* branch presupposes there is one branch. The statement actually wanted is jump-freeness, and it can be phrased over every solution at once: for all `ε > 0` there is `δ > 0` such that every coherent solution in `(K_c, K_c + δ)` is smaller than `ε`. That is provable without uniqueness, and needs only a strict bound plus the extreme value theorem on a compact interval, with a crude tail bound (`E(a) ≤ 1/a`) covering the rest of the ray. **Pattern:** when uniqueness is the blocker, check whether the consequence you actually want can be universally quantified instead of applied to "the" object.

- **Reformulate before estimating: find the function whose level sets are the answer.** `supercritical_fixed_point_exists` produced *some* fixed point and every follow-up question about the branch was vague. Factoring `R(a) = a·E(a)` and dividing by `r ≠ 0` turns `r = R(Kr/D)` into `E(Kr/D) = D/K` — pure algebra, no analysis — so the coherent branch is a level set of one function and each remaining question becomes a property of it: uniqueness is injectivity of `E`, no-jump is `E` uniformly below `1/2` away from the origin. This also corrected the ledger's plan, which had guessed strict concavity of `R`: concavity does imply `R(a)/a` decreasing, but it is a second-derivative statement about `R` where a first-derivative statement about `E` is what is wanted. Differentiating the exponential family in its natural parameter gives `E'(a) = -Cov_a(cos²θ, cos θ)` in one line.

- **Check whether a covariance is sign-definite before planning to prove it positive.** `Cov_a(cos²θ, cos θ) > 0` is true but has no rearrangement proof: symmetrising with iid copies gives `½𝔼[(X - X')²(X + X')]` with `X = cos θ`, whose integrand changes sign wherever `X + X' < 0`, so Chebyshev's association inequality and the FKG-style arguments do not apply — the exponential tilt has to beat that region quantitatively. Worth checking early, because the symmetrised form takes two lines to write and immediately tells you whether the cheap argument exists. The companion check is the derivative at the boundary: `E'(0) = 0` here, so no first-order argument at the origin can work either.

- **A class field naming a *global* object turns an existence theorem into a uniqueness theorem, silently.** `LocalSectionSynchronization` carried `phase_invariant_measure : ℝ → (probabilityPresheaf X).obj (op ⊤)` and `sync_to_section_eq`, the field declaring each local section to be a restriction of it. Everything about that was sound — the fields were obligations on instances, and every witness discharged them — and it still cost the theorem its headline reading: `global_section_from_thermodynamics` could only rule out competitors to a section the instance had already supplied. The diagnostic is syntactic and takes one pass over the class: **for each field, list the opens it mentions.** A cover's fields should mention `cover i` and `cover i ⊓ cover j` and nothing else; a field mentioning `⊤` is supplying the conclusion. The replacement field here (`section_agrees_of_phase_eq`: patches at a common phase agree on their overlap) is *weaker*, keeps the same modelling content, and lets the sheaf condition do the existence half. See `Phase4_MacroscopicScaling.lean` and open item O19.

- **When weakening a class, keep the old shape as a constructor rather than deleting it.** `LocalSectionSynchronization.ofInvariantMeasure` takes exactly the data the removed fields held and builds an instance of the new class. Three things fall out at once: it *proves* the new class is genuinely weaker (every old instance is still an instance); the existing witnesses migrate to a one-line application instead of being rewritten; and the witnesses that go through it visibly inherit the old limitation, which is worth stating as a theorem (`cortexCoverTwisted_glued`: for those instances the glued section is the input measure). Then a new witness that avoids the constructor is what demonstrates the change is real — `Examples.lean` §14, where two patches carry independently chosen mass profiles and the glued section is neither of them.

- **On a stalk-wise sheafification, restriction is reindexing, so section-level equalities reduce to pointwise ones by `rfl`.** `TopCat.Presheaf.sheafify` is `subsheafToTypes` of the "locally a germ" predicate, so a section over `U` is a subtype of `∀ x : ↥U, F.stalk x.1` and `F.map (homOfLE h).op s` is literally `fun x => s.1 ⟨x.1, _⟩`. Two consequences used throughout `Examples.lean` §14: restricting twice equals restricting once **by `rfl`**, no functoriality lemma needed; and `Subtype.ext` + `funext` reduces "these two restrictions agree" to "these germs agree", which an injectivity result on the stalk (`stalkMass_injective`) turns into an equation between numbers. That is what makes an overlap-agreement obligation dischargeable by computation instead of by construction.

- **"Picard–Lindelöf is in Mathlib" does not mean global existence is.** `IsPicardLindelof f t₀ x₀ a r L K` carries the field `mul_max_le : L * max (tmax - t₀) (t₀ - tmin) ≤ a - r`, so every existence theorem in `Mathlib/Analysis/ODE/ExistUnique.lean` produces a solution only on an interval whose length is bounded by the ball radius over the field's sup norm. **Uniqueness, by contrast, is global**: `ODE_solution_unique_univ` needs nothing but a Lipschitz bound and gives equality on all of `ℝ`. So for a globally Lipschitz field the two halves have very different costs — uniqueness is a two-line application, existence needs a continuation argument (solutions on each `[-n, n]`, coherent by uniqueness, glued by `β t := α_{⌈|t|⌉} t`) that no Mathlib lemma packages. Check for the *shape* of the hypothesis, not the presence of the theorem name, before estimating an ODE task.

- **When a general theorem is out of reach, an integrable special case can carry the claim the prose needs.** O20 asked that something run a dynamics into the Kuramoto minimum. General convergence needs LaSalle, which Mathlib lacks; but on two oscillators the phase difference obeys `Δ̇ = -2 sin Δ`, which integrates to `Δ(t) = 2 arctan(c e^{-2t})` — an exact solution on all of `ℝ`, with the potential, the order parameter and the phase-lock condition all converging by direct computation. The one analytic input was `sin (2 arctan u) = 2u/(1+u²)`, three lines from `Real.sin_arctan` and `Real.cos_arctan`. **Pattern:** before proving a limit theorem, ask whether the model has a solvable case whose limit can be computed instead. It does not replace the general theorem, and the doc-string must say so, but it is what turns "the phase transition is assumed" into "here is one that happens".

- **An overfull *float* is invisible to the overfull-hbox count, and it silently deletes text.** `Table 1` in `main.tex` had been dropping the last sentence of its caption from the compiled PDF, and the repeated check "overfull hbox count unchanged from `HEAD`" never saw it: a `table` float that does not fit produces `LaTeX Warning: Float too large for page by …pt` and no box warning at all. The content is simply not in the output. Add `grep -i "too large" *.log` to the compile gate alongside the hbox count, and verify a long caption actually survives with `pdftotext file.pdf - | grep "<final sentence>"`. The fix for a table that has outgrown a page is `longtable` with `\endfirsthead`/`\endhead`, which breaks across pages and repeats the header; wrap it in `\begingroup … \endgroup` to keep the `\scriptsize`/`\singlespacing` local, since `longtable` is not a float and will not scope them for you.

- **A hypothesis parameter is not a property of your object — check whether you get to choose it.** The previous pass read `IsPicardLindelof`'s `mul_max_le : L * max (tmax - t₀) (t₀ - tmin) ≤ a - r` as a cap on how long a local solution lives, and concluded that global existence needed a continuation argument Mathlib does not package. The first half is right; the conclusion overweighted it. `a` is the radius of the ball on which the field's bounds are *assumed*, so it is chosen by the person applying the theorem, and for a field bounded on the whole space `a := L·T` discharges the field for any `T` you like. The "local" existence theorem was already existence on an arbitrary bounded window, and the only genuinely missing step was the gluing — about sixty lines. **Pattern:** when a structure field looks like it constrains you, sort its variables into ones the object fixes and ones you supply. Here `L` and `K` are fixed by the field; `a`, `r` and the interval are free, and the inequality couples only free ones. The companion lesson is that *two* bounds were needed, not one: `IsPicardLindelof` asks for a sup bound as a field separate from the Lipschitz constant, so `kuramotoField_lipschitz` alone would not have done it.

- **A "what remains not established" paragraph is the first thing to go stale, and nothing in the build catches it.** `main.tex:171` claimed for two passes that continuity of the coherent branch in `K` was unproved and that "neither theorem covers `K = K_c` exactly", while line 165 of the same file — and the supplementary — described `coherent_branch_continuous_at_threshold` and `fixed_point_eq_zero_of_le_critical` at length. Both compile; only a reader comparing them notices. These paragraphs are written to be conservative, which is exactly why they are never revisited when the thing they disclaim gets proved. **Check, each pass that lands a theorem:** grep the manuscript for `not proved`, `remains open`, `we do not`, `is not established`, `neither theorem`, and read every hit against the current `#print axioms` output — not against memory of what the file said when the paragraph was written. The same applies to Lean doc-strings with a "what this does not establish" section, and to this file's own ranking.

- **A theorem about `deriv` is weaker than it looks: it cannot feed the FTC, or any monotonicity lemma.** `dV_dt_le_zero` had stated Lyapunov descent as `deriv (fun t => V (θ t)) t = -∑ᵢ θ̇ᵢ²` for two passes, and the ledger costed the convergence results as "near-free given `dV_dt_le_zero`". They were not, because `deriv` is junk-valued — defined to be `0` where the function is not differentiable — so an equation about it asserts nothing about differentiability, and `antitone_of_deriv_nonpos`, `intervalIntegral.integral_eq_sub_of_hasDerivAt` and everything else useful want differentiability as a separate hypothesis. The repair is mechanical (prove `DifferentiableAt` directly, then `hasDerivAt_deriv_iff` transports the existing computation) but it has to be done, and it was the entire gap between the estimate and the work. **Pattern:** when a descent or growth result is stated with `deriv`, cost the follow-on work as if the result were not yet available in usable form; prefer `HasDerivAt` in the original statement, which carries both facts at once.

- **Descent at every instant is not descent over time, and the gap is a named lemma, not a rewording.** `dynamic_potential_deriv_nonpos` quantified over `t` and said the derivative is `≤ 0` there. That constrains each instant separately and does not on its own say the trajectory settles; `Antitone (fun t => V (θ t))` does, and it comes from `antitone_of_deriv_nonpos`, which additionally needs `Differentiable` on all of `ℝ`. Then monotone convergence (`tendsto_atTop_ciInf`) closes it, given a lower bound — which here is where the zero-frequency hypothesis earns its keep, since `kuramoto_potential_unbounded_below` says no bound exists otherwise. **Pattern:** when a Lyapunov result is phrased pointwise in `t`, the three missing pieces are always the same — differentiability, global monotonicity, a bound — and it is worth writing all three rather than only the one the current prose needs.

- **Writing the "what this does not establish" paragraph is a search procedure, not a formality.** Stating precisely why `∫₀^∞ g < ∞` fails to give `g → 0` — an integrable function can spike forever on narrowing intervals — named the missing bridge (Barbalat's lemma), and checking its hypothesis against the objects at hand showed it *already holds*: the dissipation rate is bounded with bounded derivative, hence uniformly continuous. That turned a disclaimer into the cheapest open item on the list, and separated it from the LaSalle blocker it had been lumped with — velocity tending to zero is strictly weaker than converging to an equilibrium point, and needs no compactness. **Pattern:** for each scope disclaimer, name the classical theorem that would close it and check its hypotheses on the concrete objects. The gap is often in the library rather than in the model, and that is a different and much cheaper problem.

- **Compose Lipschitz estimates; do not differentiate the composite.** O22 was scoped as "bound `g' = 2∑ᵢ θ̇ᵢ θ̈ᵢ`, and bounded derivative gives Lipschitz gives uniformly continuous". The proof that landed never differentiates `g` at all. `g = Q ∘ θ` and each factor was already Lipschitz or bounded for reasons already in the development: the field is globally bounded (`kuramotoField_norm_le`), so squaring it is Lipschitz *where it is evaluated*; the field is globally Lipschitz in the configuration (`kuramotoField_lipschitz`); and the trajectory is Lipschitz in time because its derivative *is* that bounded field. Three constants multiply and the whole estimate is `abs_mul` plus `Finset.abs_sum_le_sum_abs`. The derivative route would additionally have needed the trajectory's *second* derivative to exist — a bootstrap the plan had not budgeted. **Pattern:** before differentiating to get a Lipschitz bound, check whether the function is a composite of things already known to be bounded or Lipschitz. A global bound on a vector field is worth more than it looks: it makes every nonlinearity of the field Lipschitz on the range, with no invariant region to construct.

- **`tendsto_atTop_ciSup` is the whole of a monotone-bounded tail argument.** Barbalat's lemma needs "the tail integral is eventually small". With `F T = ∫₀^T g` monotone and bounded, `tendsto_atTop_ciSup hmono hbdd : Tendsto F atTop (𝓝 (⨆ T, F T))` together with `le_ciSup hbdd T : F T ≤ ⨆ T, F T` gives `F(t+δ) - F(t) < η` for large `t` in three lines — no Cauchy-sequence characterisation, no `Filter.Tendsto.sub` bookkeeping. State the supremum inline as `⨆ T, F T` rather than naming it with `set`; the two lemmas then apply without any unfolding.

- **Widen a constant instead of case-splitting on it.** A Lipschitz constant `K` may be `0`, which breaks any `δ := ε/2K`. `obtain ⟨K', hK'pos, hKK'⟩ : ∃ K', 0 < K' ∧ K ≤ K' := ⟨K + 1, by linarith, by linarith⟩` replaces it once with a strictly positive one and the rest of the proof never mentions `K` again. Same move for the quantity defined from it: `obtain ⟨δ, hδpos, hKδ⟩ : ∃ δ, 0 < δ ∧ K' * δ = ε / 2 := ⟨ε / (2 * K'), by positivity, by field_simp⟩` supplies `δ` together with the only two facts about it the proof uses, so `field_simp` runs once at the point where the denominator is known non-zero rather than in the middle of an inequality chain.

- **A Chebyshev-association inequality does not need a product measure: cross at the mean.** The target was `∫f·W_b·∫W_a > ∫f·W_a·∫W_b` for `f` and `W_b/W_a` monovarying — classically proved by symmetrising over a square, which in Lean means Fubini, a product measure, and a change of variables in two variables. The one-dimensional route is: let `α = ∫f·W_a / ∫W_a` be the mean of `f`, pick `x₀` with `f x₀ = α` (intermediate value theorem, so `f` continuous and `α` between its endpoint values is all that is needed), and prove the *pointwise* inequality `(f x - f x₀)·(W_b x·W_a x₀ - W_a x·W_b x₀) ≥ 0`. Integrating it in `x` alone gives `W_a x₀·(∫f·W_b - α∫W_b) ≥ 0`, because the `W_b x₀` term is `∫f·W_a - α∫W_a = 0` by the choice of `α`. Everything is `intervalIntegral.integral_sub` and `integral_const_mul`, four times. Used twice in `Phase8_SelfConsistency.lean` §7 (`foldA_mul_foldW_lt`, `vonMisesM_mul_vonMisesZ_lt`). **Pattern:** whenever a covariance has to be shown positive, look for a crossing point of one factor instead of a symmetrisation of both.

- **Fold first, then compare: a change of variables can do what a tilt was expected to do.** `E(a) = 𝔼_a[sin²θ]` strictly decreasing was costed for two passes as needing `E'(a) = -Cov_a(cos²θ, cos θ) > 0`, hence differentiation under the integral sign, and the note recorded the real obstacle: symmetrised, `Cov(X², X) = ½𝔼[(X-X')²(X+X')]` has an integrand changing sign with `X + X'`, so the exponential tilt has to beat the region where it is negative. But the sign problem is exactly what the reflection `X ↦ -X` repairs, and on `[-π, π]` that reflection is the fold `θ ↦ π - θ` already written for `I₂ ≥ 0`. After it, `cos θ` runs over `[0,1]`, `e^{a cos θ}` becomes `2cosh(a cos θ)`, and both factors of the comparison are monotone in `cos θ` alone. **Pattern:** when a symmetrisation argument stalls on a sign, check whether performing the same symmetry as a change of variables *before* forming the two-point difference makes both factors monovarying. Doing it first costs one substitution; doing it inside the integral costs the tilt argument.

- **`grep` on `main.log` reports nothing at all, and it reads as zero.** `pdflatex` writes ISO-8859 bytes into the log (font and file paths), and GNU `grep -c Overfull main.log` then prints *nothing* and exits 1 — not `0` — so a compile-gate line like `overfull=$(grep -c Overfull main.log)` renders as `overfull=` and is easy to read as "no overfull boxes" when the true count is 24. `supplementary.log` happens to be clean ASCII, so the same command works there, which makes the failure look like a real difference between the two documents. Use `tr -d '\000' < main.log | LC_ALL=C grep -o 'Overfull' | wc -l`. This sits directly on the AGENTS §8 gate "check the overfull-hbox count against `HEAD` rather than assuming zero", and it silently defeats it.

- **Mathlib API notes from the monotonicity pass.** `Real.cosh_le_cosh : cosh x ≤ cosh y ↔ |x| ≤ |y|` and `Real.cosh_lt_cosh` live in `Trigonometric/DerivHyp.lean`, not in `Trigonometric/Basic.lean` where `cosh_add`/`cosh_sub` are; the product-to-sum identity is not a lemma but is `rw [Real.cosh_add, Real.cosh_sub]; ring`. `intermediate_value_Icc' (hab : a ≤ b) (hf : ContinuousOn f (Icc a b)) : Icc (f b) (f a) ⊆ f '' Icc a b` is the decreasing-endpoint version, and the `hx₀` it produces is a *beta-unreduced* application `(fun x => …) x₀`, which no `rw` will match — `replace hx₀ : … := hx₀` fixes it. A helper lemma stated as `0 < ∫ x in A..B, f x` with integrability derived inside gets `IsLocallyFiniteMeasure ?μ is stuck`: bind the measure once with `have hfi : ∀ u v : ℝ, IntervalIntegrable f volume u v := fun u v => hf.intervalIntegrable u v` and use `hfi`. And in this toolchain `le_or_lt` no longer exists (`le_or_gt`), and `push_neg` is deprecated in favour of `push Not` — `rw [not_lt]` is usually shorter than either.

- **An unconstrained class field is a symptom; the defect is that no theorem consumes it.** O2 read as "`auto_resonance` is an arbitrary function of the global section", and the obvious repair — add the predicate saying it is the presheaf restriction — would have changed nothing, because the witness had *already* been built from the restriction and no theorem mentioned the field either way. What made the field arbitrary was that `reflexive_topology_implies_self` takes the whole boundary and projects out only `predictive_model`, so its statement is invariant under replacing the resonance by a constant. The fix that bites is therefore a pair: a theorem whose conclusion *fails* for the constant (here `eq_of_avatar_eq`, where a covering family of resonant avatars determines the global state) and a theorem exhibiting the constant as a legal instance with the *same* conclusion as before (`self_of_constResonance`). **Pattern:** before adding a predicate to constrain a field, check which existing theorems mention the field. If none do, adding the predicate is a formality; write the theorem that needs it and the theorem that shows what its absence costs, in that order. And check the constraint is non-vacuous on the witness — a resonance condition says nothing on a substrate whose avatar region cannot separate two states, which is why `cortexReflexive_restrict_ne` is proved before anything is claimed for it.

- **Applying an equality of `Type`-valued functor morphisms to an element: `rfl` first, then `rw`.** Given `H : F.map i ≫ F.map j = F.map k`, the natural move `congrFun H x` or `congrArg (· x) H` fails — morphisms in the `Type` category reach their function form through `ConcreteCategory.hom`, so the elaborator sees `?m = ?m` rather than an equality of functions and reports an application type mismatch. What works, and is already the pattern in `LocalSectionSynchronization.ofInvariantMeasure`, is to turn each side of the goal into a composite by `rfl` and then rewrite: `have L : F.map j (F.map i x) = (F.map i ≫ F.map j) x := rfl` (note the order reverses), then `rw [L, R, H1, H2]`. Used in `restrictToAvatar_compatible`.

- **`lake env lean Downstream.lean` reads stale `.olean`s for anything you just edited.** AGENTS §6 recommends `lake env lean <file>` to iterate without a full rebuild, and it is right, but only for a scratch file whose *dependencies are unchanged*. Editing `Phase6` and then running `lake env lean PhysicsOfConsciousness/Examples.lean` typechecks `Examples` against the last built `Phase6`, and the new declarations come back as `unknownIdentifier` / `Invalid field` — which reads exactly like a namespace or spelling mistake and sends you looking in the wrong place. Run `lake build` once after touching an upstream file, then iterate on the downstream one.
